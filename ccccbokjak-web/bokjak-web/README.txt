복작복작 웹사이트 프로토타입 — 피그마 크기/위치 조정본

로컬 실행: index.html을 Chrome 또는 Edge에서 엽니다.

GitHub Pages 배포:
1. GitHub 계정 okko121996에서 bokjak-web이라는 공개 저장소를 만듭니다.
2. 이 폴더의 파일과 폴더를 저장소 루트에 올립니다. index.html과 assets/, fonts/, .github/이 모두 루트에 있어야 합니다.
3. 저장소 Settings > Pages에서 Build and deployment의 Source를 GitHub Actions로 설정합니다.
4. main 브랜치에 올리면 .github/workflows/pages.yml이 사이트를 자동 배포합니다.
5. 주소는 https://okko121996.github.io/bokjak-web/ 이며, 토끼 프로필 링크는 끝에 #rabbit을 붙인 주소입니다.
